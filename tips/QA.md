1. 为什么MLP中的Dropout能够防止过拟合
    原因一：防止神经元相互“抱团”：
        没有 Dropout 时，某些神经元可能形成固定合作关系。
        例如：h1 专门检测“维修” h2 专门检测“断网”
        输出层可能严重依赖：h1 + h2 → 网络故障
        模型会觉得：反正 h1 和 h2 总会同时存在，我**只**需要依赖它们。这叫神经元之间的共适应。

        加入 Dropout 后，训练时 h1 或 h2 可能随时被关闭。于是模型必须想办法让：
        h1 单独也有一定判断能力 h2 单独也有一定判断能力 其他神经元也能提供信息
        因此模型**不会把希望全部寄托在少量神经元上**。
    
    原因二：相当于训练很多不同的子网络
        假设一个隐藏层有 100 个神经元，Dropout 每次随机关闭一部分。
        每次训练时，实际参与计算的网络结构都不完全相同：
            第一个 batch：子网络 A  
            第二个 batch：子网络 B
            第三个 batch：子网络 C
        虽然参数是共享的，但可以近似理解成：
        同时训练了很多结构略有不同的神经网络。
        
        预测时再使用完整网络，效果有点类似很多模型共同投票，因此比单个网络更稳定。
        不过这只是帮助理解的近似说法，不是严格等同于真正训练了很多独立模型。

    总结：**防止依赖少部分神经元，每个神经元都要有贡献** **赛级训练多个网络众议** 


2. 为什么在多轮次训练时要使用验证集的loss来决定：竞品：验证集的acc
    第一次模型输出概率：

    类别 1：55%
    类别 2：45%

    第二次：

    类别 1：51%
    类别 2：49%

    两次 argmax 都预测类别 1，所以 accuracy 都是正确。

    但第二次模型更加不确定，因此 loss 会变大。

    又例如预测错误时：

    情况一：
    正确类别概率：40%
    错误类别概率：45%

    情况二：
    正确类别概率：1%
    错误类别概率：98%

    两种情况 accuracy 都是错误，但第二种错得更自信，loss 会大很多。

3. LSTM相较于传统RNN的优势：
    1. 传统RNN的记忆更像一个不断被覆盖的小黑板，句子一长，
    前面的内容就容易被后面的内容挤没。
    前文信息需要连续经过很多次变换：h1→h2→h3→⋯→h8
    随着序列变长，早期信息可能逐渐变弱甚至消失，这就是传统RNN难以处理长期依赖的问题
    2. LSTM的三个主要优势：
        1. 更容易保存长期信息：
            LSTM的长期记忆更新公式是：Ct=ft⊙Ct−1+it⊙gt
            其中：ft遗忘门，决定保留多少旧记忆
                  it：输入门，决定写入多少新记忆
                  gt：候选记忆，由输入xt和ht-1决定
                  ⊙：对应位置相乘
            假设模型之前已经在Ct−1中保存了：句子正在讨论银行卡
            当模型读到“书桌”“抽屉”“今天”时，这些词不需要覆盖“银行卡”的信息。
            遗忘门可以输出接近 1：ft≈1
            于是：ft⊙Ct−1≈Ct−1，Ct≈Ct-1，ht=ot⊙sigma(Ct)可以大量参考前文的重要内容作为输出，也就是继续保留原来的记忆。直到读到“它”，模型仍有机会知道“它”指的是“银行卡”。
        2. 可以**缓解**梯度消失：
            LSTM 可以通过学习遗忘门的值，让重要信息对应的梯度乘数(遗忘门)接近1
