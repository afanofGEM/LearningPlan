训练模型的结构：
1. 自定义模型：
   包括初始化类的__init__()方法
   前向传播的forward方法

2. 数据集：
   目前掌握的数据集产生方法是
    1. rand(3,4):定义矩阵形状，每个元素都服从标准正态
    2. randint(0,3,(200,))：定义矩阵形状（200，1），每个元素的取值为[0,2]
   
   目前掌握的训练集测试集切割方法是：
    1. x_train = x[:240] 因为x是行数为样本个数，列数为维度的矩阵，所以按行切割即可
       x_test = x[240:]

3. 训练函数：
   所需：训练集，标签，模型(未训练)，损失函数，优化器(Adam，动态调整lr)，训练轮数
    1. 模型开train
    2. 损失函数loss_fn:交叉熵函数
    3. 优化器：Adam，会动态lr，并且根据loss.backward()计算的元素梯度param.grad更新param
    4. torch.save保存模型

4. 评估函数：
   所需：测试集，标签，模型(已训练)，损失函数
    1. 模型开eval测试模式
    2. with torch.no_grad(): 即不需要再更新param
    3. 前向传播后，通过torch.argmax(dim=1)来求每列的最值，对于多分类问题而言
       就是（样本数，预测类）的结果，与标签尺寸一样，可以计算y==y_pred准确率

5. 细节：
    1. 关于model.train()和model.eval():
    例子 1：Dropout:Dropout的作用是训练时随机关掉一部分神经元，防止模型过拟合。
    训练模式下：
        model.train():Dropout会随机让一部分输出变成 0。
    比如原来隐藏神经元的输出：[1.0, 2.0, 3.0, 4.0]
    训练时可能变成：[1.0, 0.0, 3.0, 0.0]
    但测试时不能再随机关神经元，否则同一条数据每次预测结果可能不一样。
    所以评估模式下：
        model.eval()：Dropout会关闭随机丢弃。
    
    而决定是否需要计算梯度的是with torch.no_grad()：告诉PyTorch这段代码不用算梯度。
