不同超参数组合的不同模型的训练与选择：

1. 主函数：
    1. 包含各超参数的组合的字典：
    {
        'combination_name':'a',
        'lr':1e-3
        'dropout':0.3
    }
    2. 每一个组合训练一个最优的模型（超参数固定下的最优参数）
    3. 得到2中记录的每个模型的：
        [验证集最优数据(loss,acc,f1),超参数组合(lr,dropout),训练过程中的数据记录history(两个数据集上的loss,acc,f1),模型的保存路径]
    4. 根据这些模型验证集上最优f1，选择最终要保存的模型(路径复制以保存模型)


2. 固定超参数后的最优模型训练函数：多轮训练
    1. 初始化模型
    2. 固定模型训练的损失函数，优化器(adam)
    3. 告诉模型保存到哪里
    4. 开始训练模型（3）
    5. **边按轮训练边保存模型，直至最优**
    5. **边按轮训练边记录**它的：
        [验证集最优数据(loss,acc,f1),超参数组合(lr,dropout),训练过程中的数据记录history(两个数据集上的loss,acc,f1),模型的保存路径] 直至最优
    6. 保存每个超参数组合的最优模型


3. 固定超参数，损失函数、优化器等参数后的模型训练函数：单轮训练
    1. 对于每轮训练，先在训练集上跑一轮优化参数，得到每轮训练集的loss,acc,f1
    2. 再在验证集上跑一轮，作为评估，得到每轮验证集的loss,acc,f1
    3. 1 2 中得到的组成history多轮训练的过程量
